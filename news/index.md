# Changelog

## DIVINE 0.1.3

### Bug fixes

- [`multi_plot()`](https://bruigtp.github.io/DIVINE/reference/multi_plot.md)
  now correctly maps `group` to the `color` aesthetic in scatter plots,
  fixing a missing legend (#).

### Minor improvements

- [`multi_plot()`](https://bruigtp.github.io/DIVINE/reference/multi_plot.md)
  now warns when `group` is supplied with `plot_type = "heatmap"`, since
  it has no effect for that plot type.
